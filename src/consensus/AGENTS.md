### Critical Consensus Differences

**PoS Block Header Extensions (MUST PRESERVE)**:
```cpp
// src/primitives/block.h - Blackcoin More ONLY
uint32_t nFlags;           // Stake modifier flags (PoS validation)
uint256 nStakeModifier;    // Stake modifier for kernel hash
unsigned char vchBlockSig[65];  // Block signature (max 65 bytes)
```

**⚠️ CRITICAL**: These fields are CRITICAL for PoS consensus. Removing or modifying them will break all PoS validation.

### Consensus Rules Unique to Blackcoin More

1. **PoS Kernel Validation** (`src/pos.cpp`)
   - Uses `GetAdjustedTime()` (NOT `GetTime()`)
   - Stake modifier integration
   - Proof-of-Stake hash calculation

2. **Coinstake Transaction Rules** (`src/primitives/transaction.h`)
   - Empty output[0] for coinstake identification
   - Extended block signature validation (`vchBlockSig`)
   - Public key revelation in OP_RETURN (optional)

3. **Static Fee Enforcement** (`src/consensus/amounts.h`)
   - Fixed 100,000 sat/kvB minimum relay fee
   - No dynamic fee estimation
